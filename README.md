## 「便宜」值不值，看四个地方

### 端口大不等于回国快

雨云香港五区用的是国际大带宽，路由并不针对大陆优化。公开测评记录的去程是电信、联通绕日本，移动直连香港；回程电信走 163、联通绕美国、移动绕日本。三网平均延迟 139ms，上海移动能低到 34ms，其余地区波动明显。

这意味着你的访客如果集中在国内，体验取决于他用的哪家运营商。移动用户还行，电信、联通用户晚高峰可能会有感知。真正做国内生意、对延迟敏感的站，得往 CN2 GIA、CMI 直连这类优化线路走，价格通常翻几倍。20 元档买的是带宽，不是回国质量。

### 带宽和流量是两件事

500Mbps 说的是端口上限，不是每月能跑 500Mbps × 30 天。这个区别决定了你的账单会不会超。

雨云的处理方式是流量用完后**限速到 5Mbps**，不断网，可以买 20 元/1TB 的流量包恢复。5Mbps 大概是什么概念：一台 1MB 的页面，一秒能开 0.6 个左右。做展示站勉强能用，跑视频或下载基本停摆。

同价位的另一种做法是完全不同：野草云的普通 BGP 不限流量套餐，1 核 1G / 10GB / **5Mbps 不限流量**，19 元/月，端口小但不管总量；它的流量计费型给 50Mbps 端口 + 500GB，用完后限速 **1Mbps**，到次月 1 日重置。三种规则摆在一起看，同样是「20 元」，你买到的东西完全不一样：雨云给峰值带宽，野草云给流量池，限速阈值一个 5Mbps 一个 1Mbps。

买之前先算自己一个月跑多少 GB。日访 1000、平均页面 1.5MB、每人看 3 页，一天约 4.5GB，一个月 135GB，1024GB 那档够用得很。真正需要担心流量的是做下载、图床、视频分发的。

## 下单前必须确认的几件事

1. **结算页的续费价**。首期价和续费价是不是同一个数，只有这一步能看到。
2. **退款窗口**。雨云是 7 天内、限 3 次；野草云是 3 天内且需无滥用；天下数据不支持销毁退款。三家的政策差别很大，别默认都有后悔药。
3. **流量超额后的限速值**。5Mbps 和 1Mbps 是两个完全不同的使用体验。
4. **IP 归属**。低价香港 VPS 不保证 APNIC 香港原生 IP，可能是其他区域段但宣告到香港。对多数建站没影响，做特定地区业务要注意。
5. **能不能装面板**。宝塔、1Panel 这类面板在 2G 内存上跑得动，但要占掉几百 MB。

## 常见问题

**便宜的香港云服务器和贵的差在哪？**
主要差在线路和防御。20 元档给的是国际大带宽，回国路由绕路；200 元档给的是 CN2 GIA 或 CMI 直连，国内延迟能压到几十毫秒以内。配置反而不是主要差距，2 核 2G 在两边都有。

**不限流量是真的不限吗？**
多数情况是「限速不限量」。雨云是流量用完后限速 5Mbps，野草云流量型是限速 1Mbps 到次月重置。真正的不限流量套餐，端口通常只有 5–50Mbps，跑不快但随便跑。

**免备案是不是等于不用管合规？**
不是。免备案指的是不用做 ICP 备案，服务器放在香港。内容合规、行业资质这些该有的还得有。

**月付还是年付划算？**
先月付试一个月，测延迟、测带宽、跑一遍真实业务，确认没问题再转年付。年付的折扣通常只对首期有效，转之前把续费价问清楚。

**流量超了会被停机吗？**
雨云不会停，限速到 5Mbps，买流量包可以恢复。这一点比直接停机友好，但 5Mbps 的实际体验要提前有心理准备。
